# 设置功能与持久化

全部设置通过 `SettingsService` 和 `QSettings` 保存到平台标准配置位置。点击“应用”或“确定”保存；取消、关闭设置窗口不保存未应用的草稿。“恢复默认”只修改草稿，需要应用后持久保存。写入失败会显示错误并保留当前窗口已应用的状态。

| 设置 | 行为 | 保存键 |
| --- | --- | --- |
| 恢复上次目录 | 启动恢复最后目录和树的展开、选中、滚动位置；关闭后启动为空白 | `browser/restoreDirectory` |
| 语言 | 简体中文 / English，保存后重启生效；语言包内嵌 | `appearance/language` |
| 记住播放进度 | 在启用目录恢复的前提下，启动恢复最后文件、音视频位置与播放状态 | `playback/resume` |
| 自动播放下一项 | 自然播放结束后继续当前目录中的同类媒体；手动停止、失败不推进 | `playback/autoNext` |
| 默认倍速 | 新开音视频使用该倍速；应用变化时更新当前播放，取消临时长按加速 | `playback/defaultRate` |
| 主题 | 跟随系统 / 深色 / 浅色；应用后立即生效 | `appearance/theme` |
| 资源管理器 | 显示或隐藏左栏；与菜单、收起及展开按钮同步 | `appearance/explorerVisible` |
| 状态栏 | 显示或隐藏底部状态信息；与菜单同步 | `appearance/statusBarVisible` |

窗口尺寸和分栏位置在正常关闭时保存。最后会话的播放倍速优先于默认倍速；播放完或不可跳转媒体从头开始。目录或上次文件不可用时进入空白页，不搜索磁盘寻找替代文件。详见 [播放与会话恢复](playback.md)。

兼容旧配置：缺失字段使用原默认值；未知语言回退简体中文，未知主题回退跟随系统，不支持的默认倍速回退 1.0×。所有设置均可在无额外语言目录的发行包中使用。

检查覆盖：独立进程保存及读取设置、英文窗口与设置页、所有控件持久化、取消丢弃草稿、重新打开恢复已保存值、恢复默认的应用时机、无效配置回退，以及默认倍速与长按加速的交互。现有检查同时覆盖主题、侧栏、布局、自动下一项和最后会话恢复。
