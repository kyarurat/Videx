# 图片查看阶段验证记录

验证日期：2026-09-29。环境：Windows 11、Qt 6.11.2、MinGW 13.1、CMake 3.30.5，桌面缩放 125%。

## 已验证

- 项目及新增解码依赖编译完成；最终编译日志没有 warning/error。第三方宏重定义和 C/C++ 警告选项混用已在构建适配中修正，应用自身仍使用 C++20 和原有警告级别。
- CTest 两组测试通过：`image_checks`、`ui_checks`；原有文件浏览检查 154 项，0 失败。
- 临时样本验证 PNG、JPEG、BMP、PPM、XBM、XPM、ICO、WebP、TIFF，另验证 SVG、GIF 首帧及不含预览图的合成 Bayer DNG。验证无扩展名、误导性扩展名、MP4、未知文本、损坏 PNG、超大 SVG 和已删除文件。
- libheif 上游样本 `example.heic` 解码为 1280 × 854，`example.avif` 为 800 × 533。
- 自动写入测试用 EXIF 后，读取到相机、F2.8 光圈、1/125 秒曝光、ISO 400 和 GPS 1.300000 / 103.800000；方向 6 的 JPEG 从 180 × 120 正确旋转为 120 × 180。
- 最新加载请求优先，清空查看器后旧后台结果不恢复；图片与不支持格式来回切换正常。图片被外部覆盖保存后重新加载。
- 文件树异步加载完成前插入的当前文件不会导致图片导航错序；验证 1、2、10 的自然顺序、跳过文本、边界不循环、前后切换与高亮。
- Windows 原生窗口测试通过；已查看 900 × 600 窗口的深浅主题截图、100% 物理像素显示和中文详细信息窗口。文件切换关闭旧详细信息，格式不支持时隐藏图片工具。
- 构建输出包含 Exiv2、libheif DLL 和 WebP/TIFF/TGA/ICNS/WBMP 插件。

## 真实相机样本

样本来自 [rawpy 的公开测试目录](https://github.com/letmaik/rawpy/tree/main/test)，仅下载到被忽略的本地构建目录，未随仓库分发。

| 样本 | 解码尺寸 |
| --- | --- |
| `RAW_CANON_40D_SRAW_V103.CR2` | 1944 × 1296 |
| `iss030e122639.NEF` | 4284 × 2844 |
| `RAW_KODAK_DC50_é.KDC` | 768 × 512 |
| `RAW_SIGMA_SD9_SRGB.X3F` | 2266 × 1510 |

启用 `VIDEX_RAW_FIXTURES` 后运行原生图片测试，以上四个样本全部通过。具体机型实测范围仅限上表，不能等同于所有 LibRaw 支持机型均已实测。

## 产物与限制

本次构建位于 `build/image-viewer`。最终编译日志为 `build/final-build.log`，原生图片测试日志为 `build/image-native-final.log`，截图位于 `build/image-viewer/artifacts/images`。损坏 PNG 测试会刻意触发一次 libpng 读取错误，不代表正常图片失败。

Ubuntu 实际编译和桌面显示、MSVC 构建及完全脱离开发环境的安装包尚未验证。动画、多页翻页、HDR 专用显示、XMP 解析和可选 RAW 编解码扩展不属于当前实现；具体边界见 [图片查看说明](image-viewer.md)。

## 2026-09-30：键盘浏览与预加载

- 上下键选中文件立即打开；选中目录不改变画面、不展开目录，Enter 仍控制展开／收起。鼠标单击行为不变。
- 4096 × 3072 的 JPEG/PNG 验证后台预加载、完整分辨率缓存命中、修改后缓存失效及清空缓存。验证正在预加载的图片转为当前请求、快速切换不显示旧结果，以及主窗口按文件树顺序预读两侧图片。缓存按解码后的图片和元数据计费，上限 256 MiB，放不下两张相邻大图时优先保留下一张。
- Windows 原生测试中的加载器计时：CR2 完整解码 233 ms、NEF 3963 ms、KDC 88 ms、X3F 822 ms；预加载完成后的缓存打开均低于毫秒计时精度。这是本机样本结果，不含界面绘制，也不代表首次打开性能或任意大图性能。
- 新增运行记录：`build/preload-native.log`；本轮构建日志：`build/preload-final-build.log`。
