# Videx 0.2.0-rc.2

Windows x64 候选版本，改进播放／查看期间对外部文件操作的兼容，并修复长按加速到片尾时的崩溃。本次只发布 Windows 二进制包。

## 更新

- 视频、音频、图片跟随同目录外部重命名，更新名称、路径和文件树定位，保留播放进度、播放／暂停状态或图片视图。
- 文件删除、移出目录、音视频内容修改或替换后关闭媒体，通过状态栏提示，不触发自动下一项；图片内容修改和替换自动刷新。
- Windows 支持通知的位置按需让出冲突的独占访问，等待媒体实际卸载后解除通知，不自动重新打开；不支持通知时，可定位媒体暂停 5 秒后释放，继续播放或暂停跳转时恢复进度。
- 图片源采用可取消快照，关闭原文件后再解码及读取元数据；清理旧会话结果，避免快速切换后恢复旧画面或声音。
- 修复长按加速期间到达片尾，恢复倍速触发状态信号而无限递归的崩溃，增加对应回归。
- 保留文件树浏览、自然排序、静态图片缩放平移、RAW/HEIC/AVIF 与拍摄信息、音视频控制、同类导航及可选自动下一项等已有功能。

## 下载与运行

Windows 11 x64：下载 `Videx-0.2.0-rc.2-windows-x64.zip`，完整解压后运行 `Videx.exe`。无需安装 Qt、mpv 或开发环境，请保留 DLL 和插件目录。`SHA256SUMS-0.2.0-rc.2.txt` 提供便携包及源码包校验值；第三方许可和构建信息包含在包内。

## 验证与限制

- Windows Debug、Release 各 5 组常规回归通过；Release 原生文件操作、播放和窗口销毁检查通过。便携包另使用随包 DLL／插件复查，运行时移除开发工具 PATH。
- Ubuntu 24.04.4 WSL 2 完成 Release 构建及部分回归，完整播放仍有偶发相对跳转偏差和原生视频黑屏。
- Ubuntu 26.04.1 Hyper-V 原生桌面完成 Release 构建与 5 组常规回归；Qt 6.10.2 和 6.11.2 均有原生黑屏复现，X11 重复运行和 Wayland 尚未稳定通过。一次冻结画面网格异常未稳定复现。虚拟机使用软件 OpenGL，尚未验证真实 GPU 和人工音频。
- Ubuntu Desktop 24.04 原生桌面仍待补测，本次不发布 Linux 二进制包。已修复的片尾递归崩溃不代表 Linux 黑屏或此前未复现的关闭崩溃已修复。
- 文件让出取决于文件系统、外部程序和其他应用的占用；通知等待最多 2 秒，不保证所有网络共享和外部独占打开请求均成功。不可定位媒体不进行暂停定时释放。
- 暂停释放后的恢复仅用于当前会话；重启后的播放历史恢复仍暂缓。图片保持 100 MP／512 MiB 限制，动画和多页格式仅查看静态首帧／首页，不保证所有编码或相机变体。
