# Videx 0.2.0 · Windows x64 正式版

轻量的原生本地媒体浏览器：左侧浏览文件，右侧查看图片、播放视频和音频。本次只发布 Windows 11 x64 二进制包，Linux 暂不发布。

## 相比 0.2.0-rc.2

- 新增重启恢复：正常退出时保存最后文件、音视频进度、倍速、音量、静音和播放／暂停状态。
- 记住文件树的根目录、展开层级、选中项和滚动位置；上次文件或目录丢失、不可读时进入空白页。
- 补齐设置功能与持久化：目录恢复、播放记忆、自动下一项、默认倍速、主题、侧栏、状态栏和语言；取消不保存草稿，恢复默认需应用后保存。
- 支持简体中文与 English，语言包内嵌，保存语言设置后重启生效。
- 修复长按右键临时加速时修改默认倍速，松键后被旧倍速覆盖的问题；补齐图片读取错误及拍摄字段的翻译。
- 应用版本与 Windows 文件属性统一为 0.2.0。

保留视频／音频播放、静态图片查看、RAW／HEIC／AVIF、拍摄信息、自然排序、同类导航、自动下一项，以及外部文件重命名跟随、删除与替换处理等功能。

## 下载与运行

下载 `Videx-0.2.0-windows-x64.zip`，完整解压后运行 `Videx.exe`。运行库与插件已包含，无需安装 Qt、mpv 或开发环境。请保留全部 DLL 与插件目录。

`Videx-0.2.0-source.zip` 是本版本应用源码与构建配置；第三方依赖来源、构建配置与许可见包内文档。`SHA256SUMS-0.2.0.txt` 用于校验两个压缩包。

## 验证与范围

Windows Release 编译无新增编译警告，5 组常规回归全部通过。移除开发环境 PATH 后，便携包的原生界面、图片、文件操作、播放和窗口生命周期 5 组检查全部通过；实际程序隐藏启动到消息循环空闲，Qt、libmpv 和图片库均从包内加载。独立干净 Windows 虚拟机、所有编码／相机变体及所有网络共享并未逐一验证。

图片保留 100 MP／512 MiB 限制，动画和多页格式当前仅查看静态首帧／首页。播放记忆保存最后会话，不是多文件历史库；不可定位媒体与播放完成的文件从头开始。Linux 原生视频问题仍保留记录，本次不包含 Linux 二进制包。
