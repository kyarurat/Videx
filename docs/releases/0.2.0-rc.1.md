# Videx 0.2.0-rc.1

本版本为候选版本，新增本地视频与音频播放，并优化大图查看和大型目录导航。

## 更新

- 使用 libmpv 播放视频与音频，支持播放／暂停、跳转、音量、静音、倍速和全屏。音频独立显示名称及已有的艺术家／专辑信息，封面不作为视频流。
- 支持同类别上一项／下一项和可选的自然结束自动下一项，按文件树自然顺序导航。
- 左右键短按跳转 5 秒；右键长按临时使用 2×，松开恢复原倍速；左键长按每次后退 1 秒。文件树选中文件时也可使用，选中目录时保留展开／折叠。
- 大图先显示预览，点击原始尺寸或放大时加载原图；升级保留缩放和平移。后台原图预加载、图片及元数据缓存均有预算。
- 文件树分批查找同类媒体，缓存实际媒体类型，同目录打开复用模型。音视频切换复用引擎，纯音频避免创建视频画布，连续跳转合并处理。
- 保存窗口位置、大小和侧栏宽度；改善快速切换、损坏文件恢复和视频画布创建失败的处理。

## 下载与运行

Windows 11 x64：下载 `Videx-0.2.0-rc.1-windows-x64.zip`，完整解压后运行 `Videx.exe`，无需安装 Qt 或 mpv。压缩包提供运行库、操作说明和第三方许可材料。使用 `SHA256SUMS-0.2.0-rc.1.txt` 校验下载文件。

## 验证与限制

- Windows Release 构建及 4 组回归通过；便携包在移除开发工具 PATH 后通过原生文件树、图片、播放和生命周期检查。
- 使用有效的 20 GiB 稀疏音视频样本验证加载与跳转，使用 100 MP JPEG 和十万文件目录测量性能。结果及样本限制见 [性能验证](../performance.md)。
- 十万文件首次自然排序仍可能短暂停顿；图片保持 100 MP / 512 MiB 文件限制。
- 播放位置恢复暂缓；Ubuntu 原生图形环境和独立发行包尚未验证。本次提供 Windows 包。
- 编码支持取决于随包运行库，不保证所有容器、相机 RAW 变体、动画或多页图片均可打开。
