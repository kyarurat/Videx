# 文件浏览阶段验证记录

验证环境：Windows，Qt 6.11.2，MinGW 13.1，C++20，125% 桌面缩放。

## 本阶段验收

- CMake 配置与编译通过，没有新增编译警告。未找到可选 Vulkan 头文件的提示不影响本项目。
- CTest 离屏检查通过；Windows 原生窗口检查 154 项，0 失败。
- 验证设置窗口打开期间修改侧栏：未编辑的显隐草稿跟随主窗口，明确编辑的草稿保留，取消不覆盖已保存状态。后台文件信息刷新不改变文件树当前选择。
- 未选择文件时也监听根目录；外部删除或重命名根目录会清理文件树并提示，切换目录后旧根目录变化不影响当前浏览。Windows 在删除被监听目录的测试中可能输出 Qt 监听句柄失效诊断，目录失效恢复检查通过。
- 文件树支持回车及小键盘 Enter 打开文件或切换文件夹展开／折叠，文件夹操作不改变右侧信息；验证真实小键盘修饰标记、长按不重复切换、空选择无操作、Ctrl 组合键不触发切换。
- 外部重命名、删除当前文件后，无需再次选择即可清除失效信息并提示；切换目录解除旧文件监听。通过独立进程验证侧栏收起与恢复按钮的状态持久化，并检查视图菜单保存行为。
- 下拉框使用列表式弹出层，去除菜单式上下滚动留白；设置和文件选择窗口共用细线箭头。已查看深浅色主题下的下拉列表及文件选择窗口截图。
- 首次启动无目录时显示选择文件或文件夹提示。Qt 选择窗口使用单一“打开”按钮：选择文件后以其所在目录为根目录并高亮文件；选择文件夹则打开该文件夹，名称留空则打开当前目录。文件夹名称同步、双击目录导航、双击文件打开、回车确认、无效路径与取消均已自动操作验证。
- 选择窗口为只读，隐藏新建文件夹和文件类型筛选；直接展示所有文件。导航图标使用当前主题文字颜色，单独提供禁用配色。已验证打开窗口时图标响应主题变更，并查看深浅色截图。
- 通过两个独立应用进程验证 QSettings 保存与启动恢复：第一个进程打开并记录真实目录，第二个进程启动后直接恢复该目录；也验证了直接打开文件后恢复其所在目录。检查使用独立 INI 配置，不修改用户设置。
- 文件树展示视频、图片、文本、无扩展名文件、隐藏项和子目录。单击与键盘导航仅选择，双击文件更新右侧；双击文件夹展开或折叠，不影响当前媒体。
- “收起侧栏”隐藏整个左侧面板，为右侧让出空间。右侧顶部的“展开文件树”按钮、视图菜单或 Ctrl+B 均可恢复面板，保留展开状态及右侧内容；恢复后该按钮隐藏。
- 右侧仅显示文件名、路径、大小、扩展名和修改时间。切换根目录清空旧信息，播放控件归属右侧媒体区域，文件浏览阶段保持隐藏。视频与音频播放接入后通过媒体状态接口显示。
- 验证空目录、失效目录、将文件误作目录、已删除文件、保存配置失败的反馈；错误打开不覆盖原有有效路径。上次目录被删除时恢复未打开状态并显示说明。
- 设置中的目录恢复、主题、面板显隐和播放偏好值全部保存到配置；通过独立进程验证应用后重启恢复，以及应用后取消未提交修改不会覆盖保存值。验证恢复默认后保存、无效主题和倍速回退到默认值。播放功能仍未接入。
- 已查看深浅主题、900 × 600 最小窗口、空目录与失效目录截图；文件路径在窄窗口下换行显示。
- 原控制器、示例文件生成、模拟播放状态、演示入口及相关测试均已删除。生产代码不创建临时媒体文件，不读取媒体内容或启动解码。
